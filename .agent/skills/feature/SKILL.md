# Feature Skill

## When To Use

Use this skill when the user asks to add or change product behavior.

## Process

1. Identify the intended user-facing behavior.
2. Find existing patterns before creating new abstractions.
3. Update the smallest coherent set of backend, frontend, tests, and docs.
4. Use Context Pack to include nearby implementation, tests, and relevant specs.
5. Generate and apply patches through Patch Pipeline.
6. Run targeted tests or manual verification.
7. Update final report with behavior changes and validation.

## Completion Criteria

- The new behavior is implemented end to end.
- Existing project style is preserved.
- Tests or verification steps are recorded.
- Any incomplete edge cases are explicitly listed.
