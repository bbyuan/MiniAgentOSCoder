# Code Review Skill

## When To Use

Use this skill when the user asks for review, risk analysis, or quality inspection.

## Process

1. Read the changed files or target files.
2. Prioritize correctness, security, data loss, regressions, and missing tests.
3. Ground every finding in a specific file and line when possible.
4. Do not rewrite code unless the user asks for fixes.
5. Summaries are secondary to findings.

## Completion Criteria

- Findings are ordered by severity.
- Each finding explains impact and trigger conditions.
- Test gaps or residual risks are stated.
