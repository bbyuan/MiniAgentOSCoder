# 设计

## 默认路径

```text
打开项目 -> 描述需求 -> 开始任务 -> 必要时审批 -> 查看结果
```

“开始任务”在一个连续动作中创建 planning Run、加载必要状态并调用 start API。用户不再经过强制预检页面。

## 可选设置路径

任务输入区提供低权重的“检查运行设置”。该操作只创建 planning Run，不执行工具。设置页包含：

- 当前任务与模型是否可用。
- 安全与权限。
- Skills、MCP 服务与 Hooks。
- 返回修改任务和开始任务两个明确操作。

自动管理能力不再列成配置项。

## 任务输入

任务说明是页面唯一视觉焦点。任务类型使用紧凑原生选择器，默认值可直接使用。示例改为一个轻量填充操作，不再形成第二段长内容。项目识别信息仅保留在项目标题和切换入口中。

## 运行详情

执行画布默认占据完整宽度，只展示状态、关键指标、活动和最终结果。Inspector 由“运行详情”按钮控制。出现审批请求时自动展开 Inspector，确保阻塞操作不会被隐藏。

## 产品文案

用户面对的动作使用“开始任务、运行设置、运行详情、修改需求”等目标语言。Preflight、Inspector、Contract 等实现术语不进入默认路径。
