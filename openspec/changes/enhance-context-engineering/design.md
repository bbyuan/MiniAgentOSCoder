# 设计

## 上下文来源

初始 Context Pack 分成两类：

- 必选项：用户任务、当前计划、项目画像和项目级 `AGENTS.md` 规则。
- 候选项：项目/长期记忆、相关源码片段、相关测试片段和符号/导入关系说明。

## 任务感知检索

检索器从任务中提取标识符、路径片段、英文词和中文二元词，并为索引片段计算确定性分数：

1. 路径或符号直接命中获得最高加权。
2. 内容命中、测试文件和与命中文件存在导入/测试关系获得额外加权。
3. 低信息停用词不参与评分。
4. 相同文件只保留有限数量的最高分片段，避免单文件占满预算。
5. 没有直接命中时选择少量入口文件和测试文件作为安全回退。

每个片段携带 `path`、`start_line`、`end_line`、`score` 和 `matched_terms`，Context Pack Builder 继续负责预算适配、压缩和遗漏记录。

## 项目规则

规则发现顺序为工作区根目录 `AGENTS.md`、工作区 `.agent/AGENTS.md`。内容在进入上下文前经过密钥脱敏和长度限制。规则项类型为 `project_rules`，属于压缩保护项。

## 当前补丁

成功应用补丁后，Runtime 用规范化 unified diff 替换旧的 `current_diff` 项。它和最新 observation 一样受压缩保护，直到 Run 终止。

## 失败处理

索引缺失时在内存中重建；索引损坏、规则读取失败或单文件无法解码时跳过该来源，但不阻断 Run。所有选择结果都通过 Context 解释数据和 Trace 可观察。
