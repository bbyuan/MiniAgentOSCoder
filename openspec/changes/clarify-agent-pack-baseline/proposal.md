# Change: Clarify AgentPack Baseline

## Motivation
AgentPack is an important platform concept, but the Web UI currently exposes the term before explaining why users should care. This makes the feature feel technical and unfriendly.

## Proposal
- Present AgentPack as a user-facing run baseline while keeping the technical AgentPack name in explanatory copy.
- Add an explainer section that describes what the baseline contains and what it excludes.
- Add purpose cards for control, comparison, and safe handoff.
- Rename primary actions and related sidebar/preflight labels to baseline-oriented language.

## Non-Goals
- Do not change AgentPack manifest generation or versioning semantics.
- Do not package or build the desktop shell.
