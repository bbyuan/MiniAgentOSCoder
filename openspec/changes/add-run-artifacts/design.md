# Design: Add Run Artifacts

## Context

The backend already compiles `AgentContract`, records trace events, scans workspaces, and exposes API endpoints. This change adds an artifact layer that gives the frontend a stable, display-ready runtime snapshot.

## Goals

- Return a real plan generated by backend logic.
- Return display-ready context explanation.
- Return diff/test summary objects even before patch execution.
- Keep artifact generation deterministic and local for now.

## Artifact Shape

```text
RunArtifacts
  plan[]
  context_explanation[]
  diff_summary
  test_summary
  trace_summary[]
```

## Decision

P0 artifact generation is deterministic. It uses task mode, project profile, and runtime state instead of calling a model. This keeps the workbench useful before full model orchestration is implemented.
