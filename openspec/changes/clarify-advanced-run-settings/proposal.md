# 重构运行前高级设置

## 背景

当前“高级设置”直接展开完整运行检查器，将可编辑设置、自动管理状态和运行后证据混在八个标签中。用户难以判断此时究竟需要调整什么，窄栏中的大量技术元数据也造成中英文混杂和阅读负担。

## 变更内容

- 将运行前高级设置从完整运行检查器中独立出来。
- 启动前只提供“安全与权限”和“扩展能力”两个可配置页面。
- 隐藏启动前无须处理的上下文压缩、记忆、检查点、报告、轨迹和运行证据。
- 使用宽幅设置区域和清晰导航，避免将复杂配置挤在右侧窄栏。
- 本地化风险、策略、效果类型和扩展元数据等普通术语。
- 保留 Skills、MCP、Hooks、Sandbox、Provider 等产品或协议专有名词。

## 能力影响

- `desktop-workbench`：调整 planning 阶段高级设置的信息架构和本地化要求。

## 不在本阶段

- 改变治理、扩展或运行时 API。
- 删除运行后的检查器和证据视图。
- 重新生成桌面安装包。
