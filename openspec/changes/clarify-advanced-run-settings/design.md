# 设计

## 启动前与运行后分离

planning 阶段的高级设置只回答“用户现在可以改什么”：

1. 安全与权限：选择 Sandbox 安全级别，并覆盖具体工具的审批或禁用策略。
2. 扩展能力：启用当前任务需要的 Skills、MCP 服务和 Hooks。

上下文构成、记忆管理、Guard 决策、执行记录、检查点、报告和轨迹属于自动管理或运行证据，继续保留在执行开始后的运行检查器中。

## 页面结构

高级设置以内嵌宽幅区域呈现在运行准备内容之后。左侧为两个稳定导航项，包含名称和一句用途；右侧只渲染当前配置表单。移动端改为顶部两项分段导航。

## 减少噪声

- 安全设置模式隐藏执行后端、能力保证、平台限制和 Guard 决策。
- 扩展设置模式隐藏运行证据。
- 空能力使用一条明确空状态，不显示警告。
- 原始 ID、可执行文件和事件名仅作为必要技术元数据，普通风险与策略术语使用当前语言。

## 本地化边界

中文界面的普通产品文案、风险等级、工具策略、效果类别和失败策略必须为中文。用户项目提供的名称、描述、命令、文件路径和协议专有名词保持原值，避免错误翻译代码身份。
