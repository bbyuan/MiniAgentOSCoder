# Change: Clarify Product Onboarding Flow

## Motivation
The Web app should make the product journey clear before the user starts a run. Users need to understand how opening a project leads to governed execution, live steering, and verifiable results without reading dense settings panels.

## Proposal
- Add a concise session flow to the project launcher.
- Add a concise run flow to the task setup screen.
- Keep the primary actions unchanged while making the next steps visible.
- Preserve browser/Web-only delivery and avoid desktop packaging.

## Non-Goals
- Do not change run creation, model setup, or project selection behavior.
- Do not build the desktop shell in this change.
