# Add Project Readiness Center

## Why

After opening a project, users need a clearer starting point than a blank task composer. The workbench should explain which setup items matter, which are optional, and what task patterns are reasonable first actions.

## What Changes

- Add a project readiness center above the new-task composer.
- Surface model readiness, verification detection, and AgentPack baseline state.
- Add guided first-task chips that populate a concrete prompt and matching run mode.
- Keep setup actions direct: configure model or open AgentPack details.
- Show AgentPack baseline state in the project sidebar for quick orientation.

## Non-Goals

- No desktop packaging changes.
- No cloud sync or account onboarding.
- No automatic task execution from a suggestion chip.
